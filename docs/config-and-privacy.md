# 配置说明（config.json）与本地隐私


```json
{
    "portalHost": "https://sam.ahpu.edu.cn",   // 认证门户
    "userIdEnc": "AQAAANCMnd8BFdERjHoAwE/...", // 学号密文（DPAPI）
    "service": "校园网",                        // 出口：校园网/中国移动/中国联通/中国电信
    "autoStart": true,                         // 开机自启
    "showNotify": true,                        // 登录结果通知气泡
    "autoRelogin": true,                       // 断线自动重连
    "passwordEnc": "AQAAANCMnd8BFdERjHoAwE/..." // 密码密文（DPAPI）
}
```

**学号和密码都不是明文**：都用 Windows DPAPI 加密，密文只能由「当前 Windows 用户 + 当前这台电脑」解开。
旧版本留下的明文 `userId` / `password` 会在新版启动时自动迁移成密文（迁移完文件里就查不到明文了）。

**出口不会自动换**：新配置默认出口是「校园网」。如果配置的出口不在门户返回的可选列表里，
程序会照配置的出口去试，失败时明确提示"出口不在可选列表"，
不会静默换成列表里的第一家运营商（避免无意中走计费出口）。

> **认证地址只填「协议 + 主机 + 端口」**（如 `https://sam.ahpu.edu.cn`），
> 不要带 `/eportal/index.jsp?wlanuserip=…` 这类路径和参数：后缀那些参数是每次会话
> 随机下发的一次性值，带上就会拼出错误的认证地址。粘了整段也没关系——
> 点「解析链接」或直接保存都会自动截成 origin。

- 把程序目录发给别人，对方解不开你的学号和密码，日志会提示「…无法解密，请重新输入」
- 换人使用：删掉 `config.json`，让对方重新填学号密码
- 学号/密码两项任一解不开时，保存会保留原密文，只是切开关不会把它们冲掉

## 本地数据与隐私

| 数据 | 位置 | 保护方式 |
|---|---|---|
| 学号、密码 | `config.json` | DPAPI 密文（当前用户 + 本机） |
| 认证门户、出口、开关 | `config.json` | 明文（不含个人信息） |
| 运行日志 | `login.log` | 自动脱敏：学号留前 4 位，`ticket` / `sessionId` / `userMac` 打码 |
| 门户域名上次解析到的 IP | `dns_cache.json` | 明文 IP + 时间戳，仅供 DNS 故障回退；30 天过期，不含个人信息 |

- 日志超过 1 MB 自动轮转，保留 `login.log.1 ~ .3`；托盘右键「清空日志」一键删除
- 升级到 1.0.2 后，历史日志会按同样规则重写一遍，旧明文一并清掉
- **能防**：误发文件夹、误传 GitHub、云盘同步、同机其他 Windows 用户、换电脑后旧密文失效
- **防不住**：以你身份运行的恶意程序（它可以直接调 DPAPI 解密）、管理员权限、屏幕截图。
  想要更强的保护只能每次手输密码，那就失去自动登录的意义了

## DNS 回退与「修复 DNS」（1.1.0 起）

**不需要新增配置字段**：这两项能力默认开启、全自动，`config.json` 的七个字段保持不变。

- **连接层回退**：每次成功连上门户域名时，把「域名 → IP」记进程序目录下的
  `dns_cache.json`（30 天过期）。域名解析失败时自动改连缓存 IP；HTTP Host 头、
  TLS 域名（SNI）与证书校验仍按原域名进行，缓存 IP 指向假服务器会被证书校验拒绝，
  安全性不降级。缓存只对门户域名族生效，不记录探测用的域名。
- **证书失败会清缓存**：TLS 校验失败时删除对应域名的缓存条目，避免 DNS 被劫持时
  把错误 IP 留下拖垮后续回退。写盘用临时文件 + 原子替换，断电不留半截文件。
- **一键修复**：托盘右键「修复 DNS」会定位持有校园网地址（10.x）的网卡，执行
  `Set-DnsClientServerAddress -ResetServerAddresses` 恢复 DNS 自动获取并清系统 DNS
  缓存，成功后自动重登。
  - **需要管理员权限**：已是管理员时静默执行；否则弹 UAC，由你确认后才会改动网卡，
    取消授权不执行任何命令。
  - 这是本工具**唯一**会修改系统网络设置的动作，且只在主动点菜单时发生；
    巡检阶段只告警，不会私自改网卡配置。
- **删除缓存**：直接删掉 `dns_cache.json` 即可，程序下次启动会重建；缓存里没有
  学号、密码或票据。
